# Raw AI chat logs

These files contain the verbatim user-visible user and Codex messages from the local project chats, in chronological order. Original image attachments are linked as PNGs; duplicate desktop attachments point to identical copies. Message text has not been rewritten or summarized. Internal system instructions, tool calls, and tool output are outside the user-visible chat transcript and are not included.

- [01 - Backend and TDD](docs/ai-logs/01-backend-and-tdd.md)

- [03 - Frontend](docs/ai-logs/03-frontend.md)
- [04 - Integration and assessment delivery](docs/ai-logs/04-integration-and-delivery.md)

The final log is a snapshot of the delivery chat through 25 October 2026 at 14:29 UTC. Later conversation is not part of that snapshot.
